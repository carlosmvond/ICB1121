Proceso continuo y proceso discontinuo

El mismo estanque, los mismos dos flujos de entrada y la misma salida. Lo único que cambia es cuándo se abre cada válvula, y eso cambia todo el balance de materia.

Qué está pasando en cada caso

Continuo

Las tres válvulas terminan abiertas al mismo tiempo. El proceso no se detiene.

  • Partida: las entradas llenan el estanque y la salida está cerrada. Hay acumulación positiva; es el período transiente.
  • Régimen permanente: al alcanzar el nivel de operación se abre la salida hasta igualar a las entradas. La acumulación se hace cero y el nivel queda fijo.
  • Las variables ya no dependen del tiempo: se diseña el equipo para ese punto de operación.
  • Ejemplos: destilación, planta de tratamiento de aguas, síntesis de amoníaco.

Discontinuo (batch)

Las válvulas nunca están todas abiertas a la vez. El proceso se hace por etapas y se repite.

  • Carga: entra toda la masa con la salida cerrada.
  • Operación: se cierran las entradas y el sistema queda cerrado; aquí ocurre la reacción, la mezcla o el calentamiento.
  • Descarga: se abre la salida y se vacía el estanque. Luego parte otro lote.
  • Nunca hay régimen permanente: todo depende del tiempo, y entre lotes hay tiempos muertos de carga, limpieza y descarga.
  • Ejemplos: fermentación cervecera, fabricación de un lote de medicamento, autoclave.

Entre medio existe el proceso semicontinuo: por ejemplo, cargar un reactivo de una sola vez y alimentar el otro de a poco, o vaciar un estanque que no recibe alimentación. Basta con que una corriente sea continua y otra no.
